两个 margin 相遇，只留最大的那个

相邻的垂直 margin 不会相加，而是折叠成其中的最大值——这是布局里最容易被"看着不对但说不出哪不对"缠住的地方。 下面两个场景是真实现场。切换右侧的修复方式，看它和左侧基准差在哪，标注线上的数字会跟着变。

折叠发生的条件

  • 两个块级盒子属于同一个 BFC
  • 它们之间没有 border、padding、行内内容或清浮动
  • 只发生在垂直方向，水平 margin 从不折叠

BFC 为什么能阻断

CSS 2.1 §8.3.1：创建了新 BFC 的元素，其外边距不与流内子元素折叠。

相邻兄弟的折叠还要求二者同属一个 BFC。BFC 是一堵墙，墙内墙外的 margin 碰不到一起。

哪些方式能创建 BFC

  • display: flow-root —— 首选，零副作用
  • overflow: hidden / auto / scroll
  • float 非 none
  • position: absolute / fixed
  • display: inline-block / table-cell / flex / grid

两个别踩的坑

  • 上面 padding-top / border-top 也能阻断折叠，但那不是 BFC——是"边界"这条独立规则。面试里分清楚会加分。
  • overflow: hidden 顺手裁剪溢出内容、可能改变 sticky 的滚动容器。flow-root 没有这些问题。
